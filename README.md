# Floppin' Fantasy Basketball Analytics

A personal, noncommercial analytics project supporting fantasy basketball decision-making in a private Yahoo Fantasy Basketball keeper league.

The project is intended to use Yahoo's authorized Fantasy Sports API for read-only access to league information, rosters, draft results, transactions, standings, and historical statistics.

Data will support nine-category player valuations, keeper decisions, draft preparation, roster optimization, and trade analysis.

This project is not affiliated with Yahoo Sports and does not provide commercial services.

Private league information, account credentials, and API tokens will not be published.
